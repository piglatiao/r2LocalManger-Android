# R2 存储管理器 · Android 版

从桌面版 `r2LocalManger`（Electron + AWS SDK S3）移植的 Android 客户端工程。当前阶段为**需求与原型**，尚未编写业务代码。

- 目标平台：Android 14 (API 34) 及以上
- UI 方案：Kotlin + XML 布局 + **ConstraintLayout**（按要求使用约束性布局，不用 Compose）
- 本目录可整体独立成仓，不依赖桌面工程

## 目录

```
r2-manager-android/
├── README.md
├── docs/
│   ├── 01-需求规格说明书.md      # 范围、功能需求、页面地图、验收标准
│   ├── 02-接口与配置清单.md      # R2 / Cloudflare 接口、配置项、阈值、仓库层草案
│   └── 03-页面原型与交互说明.md  # 设计系统、每页 ConstraintLayout 结构、手势
└── prototype/
    └── index.html               # 可点击原型（交互模式 + 全部页面总览）
```

## 怎么用原型

用浏览器打开 `prototype/index.html`：

- 顶部「交互模式」：单机可点击原型，页面内的按钮/列表项/手势区可跳转，底部导航可用。
- 顶部「全部页面」：一次性平铺全部页面，便于评审时全局比对；点任意一屏可切回交互模式定位。

原型是纯静态 HTML/CSS/JS（内联样式，零依赖），可直接放进评审文档或发给他人。

## 读文档的顺序

1. `docs/01-需求规格说明书.md` —— 先看第 1、3、5 章，确认范围和移动端交互改造是否认可。
2. `docs/02-接口与配置清单.md` —— 确认接口与阈值全部沿用桌面版，无遗漏。
3. `docs/03-页面原型与交互说明.md` —— 落地时按页对照实现。
